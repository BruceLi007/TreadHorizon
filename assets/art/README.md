# 素材投放说明

把美术素材按类别丢进下面的文件夹，然后跑体检：

```powershell
python scripts\audit-assets.py
```

它会告诉你每个文件能不能直接用、哪里要返工。

---

## 目录

```
assets/
├─ art/              ← 你的原始素材（我不会改动这里）
│  ├─ icons/         顶栏图标：搜索、加号、统计、设置…
│  ├─ markers/       地图标记（飞镖）
│  ├─ illu/          空状态插画、装饰图形
│  └─ textures/      背景纹理、纸感、噪点
└─ generated/        ← 我处理后的规范资产，别手改
```

---

## 格式优先级

```
SVG  ＞  PNG（透明）  ＞  WebP  ＞  JPG
```

有矢量一定给矢量：能任意改颜色、放大不糊、体积通常只有 PNG 的十分之一。

---

## 各类素材的具体要求

### 顶栏图标（icons/）

| 项 | 要求 |
|---|---|
| 格式 | **SVG** |
| 尺寸 | `viewBox="0 0 24 24"`，内容四周留 2px |
| 描边 | 统一 1.5px，`stroke-linecap="round"`、`stroke-linejoin="round"` |
| 颜色 | `stroke="currentColor"`（我用 CSS 控制颜色，不用你配色） |
| 不要 | 内嵌位图、文字、滤镜、多图层 |

一套图标**粗细必须统一**，混用 1px 和 2px 放在一起会很明显。

### 地图标记（markers/）

| 项 | 要求 |
|---|---|
| 格式 | **SVG** |
| 画布 | `viewBox="0 0 100 100"` |
| **锚点** | 尖端固定落在 **(50, 100)**，这是和地图坐标对齐的位置 |
| 颜色 | 单色路径，`fill` 留空由我上色（琥珀=去过，冷蓝=想去） |

### 插画（illu/）

| 项 | 要求 |
|---|---|
| 格式 | SVG 优先；否则 **透明 PNG @2x** |
| 宽度 | 480–640px（2x 就是 960–1280） |
| 不要 | 白底、内嵌图片、渐变网格 |

### 纹理（textures/）

| 项 | 要求 |
|---|---|
| 格式 | JPG / WebP |
| 尺寸 | 1024×1024，**无缝平铺** |
| 透明 | 不需要，我叠 `blend-mode` |
| 色调 | 偏灰、低对比，否则会盖住内容 |

## 三个最容易翻车的点

### ① 白底

AI 生成图和设计工具导出默认都带白底。

**给我 PNG 必须是透明背景**，否则放到深色界面上就是一个白方块。

体检脚本会专门检查这个（看四角是不是纯白）。

纯色背景我可以用脚本抠掉；渐变或复杂背景抠出来会有毛边，得你在工具里自己导出透明版。

### ② 颜色模式

必须是 **sRGB / 8-bit**。设计软件默认可能导出 CMYK（印刷用），浏览器里会明显发灰发暗。

### ③ 设计源文件

`.psd` `.ai` `.sketch` `.fig` `.procreate` 这些我**读不了**。
请导出 SVG 或透明 PNG。

## 命名建议

```
icon-search.svg
icon-plus.svg
marker-dart.svg
marker-dart-wish.svg
illu-empty.svg
texture-paper.jpg
```

小写、连字符分隔、带类别前缀。批量处理时我能按前缀套用不同的规则。
